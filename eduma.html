كيف ترفع هذا الموقع على GitHub Pages مجاناً؟

يمكنك نشر هذا الموقع بالكامل في دقائق معدودة على منصة GitHub وإتاحته للجميع عبر رابط مجاني سريع ودائم.

Terminal / Command Prompt bash

# 1. Initialize local repository

git init

# 2. Add files and commit

git add .

git commit -m "Initial commit - Eduma Educational Platform"

# 3. Connect to GitHub Repo & Push

git branch -M main

git remote add origin https://github.com/USERNAME/eduma-platform.git

git push -u origin main

خطوات نشر الموقع على GitHub Pages

دليل خطوة بخطوة لجعل موقعك متاحاً أونلاين

1

إنشاء مستودع جديد (New Repository)

قم بالدخول إلى حسابك في GitHub.com وانقر على زر New Repository. سمّ المستودع باسم مثلاً my-educational-site ثم اضغط Create Repository.

2

حفظ الملفات محلياً

احفظ كود هذا الملف باسم index.html داخل مجلد على جهازك.

3

رفع الملفات عبر Terminal / Git

# افتح مجلد المشروع في Terminal ثم نفّذ الأوامر:

git init

git add .

git commit -m "إطلاق الموقع التعليمي"

git branch -M main

git remote add origin https://github.com/YOUR-USERNAME/my-educational-site.git

git push -u origin main

4

تفعيل GitHub Pages

ادخل إلى صفحة المستودع على GitHub -> اذهب إلى Settings -> ثم من القائمة الجانبية اختر Pages -> اختر فرع main واضغط Save. خلال دقيقة سيعطيك GitHub رابط موقعك المباشر!
